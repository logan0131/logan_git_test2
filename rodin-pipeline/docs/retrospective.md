# Rodin Pipeline 회고 · 문제 해결 체크리스트

*Retrospective and troubleshooting checklist for the Rodin → PrusaSlicer pipeline app (Korean; the checklist section is the part to keep at hand).*

v0.4.12 기준. 38개 커밋, 엔진 단위 테스트 44개, 브라우저 스모크 테스트 1개로 마무리했습니다.

## 1. 완성된 것

```
Rodin Face-Color 3MF → 불러오기 → 실물 필라멘트 → 색 병합(그늘 재판정) → 컬러믹스 수치(가상 익스트루더)
→ 미리보기(3D + 색지도, 조각 선택, 브러시, 되돌리기) → PrusaSlicer 3MF 내보내기 → (선택) 노마드 왕복
```

- 한 화면에서 끝나는 React/Three.js 앱. 계산은 Color Mix Lab 포크의 엔진이 맡습니다.
- 팔레트 색 수, 실물 익스트루더 수 모두 PrusaSlicer 2.9.6의 한계(실물 + 가상 255)까지.
- 작업(모델 + 현재 색 + 템플릿 + 설정)은 `rodin-pipeline/user-data/` 폴더에 자동 저장.
- 내보내기 전 검증 6항목과 "슬라이서 · 프린터 확인"으로 순서 실수를 미리 잡습니다.

## 3. 개발 과정에서 한 실수

- 패치 스크립트가 중간에 멈춰 파일이 반쯤 바뀐 채 남은 적이 있다. 이후 모든 패치는 앵커마다 개수 검사를 하고 하나라도 어긋나면 아무것도 쓰지 않게 했다.
- 성능: 차트 흡수 루프가 차트 수 × 면 수였다. 수십만 면에서 체감됐고 O(n)으로 다시 썼다. 자동 테스트는 작은 모델이라 못 잡는다.
- 패널 크기가 바뀌었는데 색지도가 이전 크기에 맞춰 있었다. "일부만 쓴다"는 보고의 원인은 알고리즘이 아니라 갱신 누락이었다.
- 없는 키를 읽을 때 404를 내서 콘솔이 빨갛게 됐다. 204로 바꿨다. 정상 상황이 오류처럼 보이면 진짜 오류를 못 찾는다.
- 자동 저장 표시가 저장 전에 "저장됨"을 보여 새로 고침 시 작업을 잃을 수 있었다. 저장을 시작하는 순간 "저장 중"으로 바꿨다.
- 다운로드 직후 임시 URL을 즉시 해제했다. 일부 브라우저와 큰 파일에서 다운로드가 조용히 취소된다.
- `pkill -f "vite preview"`가 자기 셸까지 죽였다. 포트 기준(`fuser -k 4174/tcp`)으로만 정리한다.
- 원본 랩을 포크하면서 MMU 전제(SEMM=1)를 검토하지 않았다. 앱은 처음부터 XL이 대상이었다.

## 4. 또 일어나기 쉬운 것 (체크리스트)

**내보내기 전**
- [ ] 앱 상단 버전이 최신인가 (실행 파일은 켤 때마다 최신을 받아 온다. 브라우저 새로 고침).
- [ ] 실물 E1~E5 = PrusaSlicer 익스트루더 1~5 프리셋 = XL 툴 1~5 필라멘트. "슬라이서 · 프린터 확인"이 초록인가.
- [ ] PrusaSlicer에서 필라멘트를 바꿨다면 템플릿 3MF를 다시 저장해서 앱에 다시 넣었는가 (색·이름·SEMM·베드 크기를 여기서 읽는다).
- [ ] "템플릿 프린터 설정 포함"은 필요할 때만. 켜면 PrusaSlicer 프리셋이 템플릿 것으로 바뀐다(수정됨 표시).
- [ ] 팔레트 색 수는 필요한 만큼만. 가상 색이 늘수록 툴 체인지와 퍼지가 늘어난다.
- [ ] 버튼 아래 결과 상자가 초록인가. 빨간 상자면 그 문구가 원인이다.

**PrusaSlicer에서**
- [ ] 2.9.6 이상인가 (17색 이상은 2.9.5 이하에서 못 읽는다).
- [ ] 이상한 파일을 연 뒤에는 프린터·프린트·필라멘트 프리셋을 시스템 프리셋으로 되돌린 뒤 새 파일을 열 것.
- [ ] 색은 레이어 미리보기에서 확인. 플레이터의 색은 JSON의 표시 색이라 순서 오류가 안 보인다.
- [ ] "Maximum width of a segmented region"을 0이 아니게 쓸 때만 기본 익스트루더가 내부 색이 된다.

**저장·브라우저**
- [ ] 상태 표시줄 오른쪽이 "저장: 폴더"인가. "브라우저"면 주소(포트)가 바뀌는 순간 다른 저장소를 본다.
- [ ] 백업은 `rodin-pipeline/user-data/` 폴더째로.
- [ ] 다운로드가 안 보이면 브라우저 다운로드 목록에서 차단 여부 확인 후 "다시 받기".
- [ ] 수십만 면 모델은 색지도 만들기와 내보내기에 수십 초 걸린다. 상태 표시줄의 "만드는 중"을 기다릴 것.

**브러시·선택**
- [ ] 다른 조각을 오염시키지 않으려면 "선택한 조각 안에서만"이 켜져 있어야 한다.
- [ ] 드래그 한 번이 되돌리기 한 단계. Ctrl+Z / Ctrl+Shift+Z, 깊이 20.
- [ ] 노마드에서 칠한 OBJ를 다시 읽으면 팔레트 색으로 스냅된다. 상태 표시줄의 최대 ΔE가 크면 팔레트에 없는 색을 칠한 것이다.

## 5. 마무리

원본 Color Mix Lab의 엔진 위에 Rodin 전용 불러오기, 그늘 재판정 병합, 노마드 왕복, 3D와 2D를 오가는 조각 선택과 브러시, 폴더 저장, 그리고 PrusaSlicer 2.9.6 규격의 내보내기까지 올렸습니다. 막힐 때마다 원인을 소스에서 확인하고 검증을 앞단으로 옮긴 덕에, 마지막 두 오류는 슬라이서가 아니라 앱이 먼저 잡게 됐습니다. 수고 많으셨습니다.
